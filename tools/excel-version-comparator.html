Important: This version uses ExcelJS for the output workbook, specifically so that background fills, bold fonts and borders are written as real Excel formatting. The whole affected row receives a light pastel shade, while the exact cell containing a difference is highlighted light yellow. For text changes, the entire cell containing a change is highlighted light yellow. Within text cells, only the changed portion is bold and red; unchanged text remains normal. Use the Word wrap option before comparison if cell contents should wrap in the output Excel file. All output cells receive borders. Row Changes and Change Details also show the exact changed portion of text in red. Word wrap is enabled by default, and the worksheet zoom can be adjusted before comparison (default: 55%).
